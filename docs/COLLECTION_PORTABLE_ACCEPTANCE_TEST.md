# 收藏集建议与缺失内容：便携版验收用例

- 用例 ID：`WT-COLLECTION-PORTABLE-001`
- 对应任务：`TASK-D-UX-003-R2`、`TASK-D-UX-003-R3`
- 测试类型：真实便携版、人工端到端回归
- 数据安全：不删除收藏集和影视记录；执行“补充缺失内容”前必须先检查预览

## 测试目标

用一个连续流程确认以下行为：已有收藏集不会再次作为新集合推荐；TMDB 确认的完整单季剧不会出现；用户忽略的建议在重启后仍被记住并可恢复；已绑定 TMDB 父剧的收藏集能够检查缺失季，而且不会把已有季重复加入。

## 前置条件

1. 使用最新 `watch-tracker.exe`，在“设置 → 关于”记录版本号和 Git 提交码。
2. TMDB 凭据有效且网络可用。
3. 片库中至少准备以下四类现有数据：
   - 已属于任意收藏集的衍生作品，例如已经加入“罪恶黑名单”的《罪恶黑名单：救赎》；
   - 已经建立收藏集的系列，例如“黑镜”；
   - TMDB 可确认只有一个已播常规季、并且该季已在片库中的剧集；
   - 已绑定 TMDB 父剧、片库中确实缺少至少一季的系列。
4. 测试前退出程序并保留当前数据库恢复点或外部备份。

## 操作与预期结果

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 打开“系列与收藏集”，执行“扫描片库归组建议”；如存在旧缓存，使用强制刷新。 | 扫描能够结束；界面显示可处理、已完整/单季、已有集合覆盖、已忽略、歧义和无法确认的分类统计。 |
| 2 | 检查建议列表。 | 已经被收藏集覆盖的《罪恶黑名单：救赎》不再作为独立建议；已经建立并覆盖现有成员的“黑镜”等集合不重复出现。 |
| 2A | 保持建议结果存在，点击左侧任意具体收藏集。 | 右侧立即切换为该收藏集的具体成员；全库“TMDB 只读建议”和待确认项全部隐藏，不得混入收藏集详情。 |
| 3 | 检查准备好的完整单季剧。 | TMDB 已确认只有一个已播常规季且片库已拥有该季时，不显示可应用建议；第 0 季、特别篇和未来季不应使它被误判为缺季。 |
| 4 | 对任意一条仍然有效的可处理建议选择“不再推荐”。 | 该建议立即离开默认列表，“已忽略建议”计数增加；records、收藏集成员和观看状态均不改变。 |
| 5 | 完全退出便携版，重新启动并再次扫描。 | 被忽略建议仍不出现，证明忽略决定不是只存在于当前界面或 TMDB 缓存。 |
| 6 | 打开“已忽略建议”，恢复刚才的项目，再次扫描。 | 项目重新获得推荐资格；恢复动作本身不新建收藏集、不修改影视记录。 |
| 7 | 打开已绑定 TMDB 父剧且确有缺季的收藏集，选择“检查缺失季”。 | 能打开缺失季预览；已有季被识别为已存在且不可重复选择，只列出真正缺少、已播且可确认的常规季。 |
| 8 | 取消预览，不执行最终补充。 | 返回收藏集详情；影视记录总数、收藏集成员数和观看状态保持不变。 |
| 9 | 准备一个 IMDb 同时返回电影和剧集的条目，其中电影没有 `belongs_to_collection`。重新扫描。 | 无效电影结果不会进入“多个有效 TMDB 匹配”；如果剧集仍有真实归组或缺季差异，直接生成唯一只读建议。 |
| 10 | 准备一个 IMDb 同时返回电影合集与完整单季剧集的条目。重新扫描。 | 完整单季剧集归入“完整排除”，只显示可产生实际差异的电影合集建议。 |
| 11 | 检查一个电影合集，其中当前只有一部作品已上映，其他作品均未上映。 | 不生成合集建议，不要求人工选择；统计归入“非合集/无差异”。 |
| 12 | 在候选仍有多个有效结果时查看选择卡，然后关闭而不应用。 | 卡片显示原名、年份、TMDB ID及目标合集/父剧；关闭前后 records、collections、members、generation 与 outbox 均不变化。 |

## 通过标准

- 步骤 1 至 8 全部符合预期。
- 全程没有重复建议、重复季、同 IMDb 记录重复创建或已有字段被覆盖。
- 没有出现无法结束的扫描、空白弹窗或必须返回主界面才能继续操作的问题。
- 测试结束后记录版本、Git 提交码、执行时间和各步骤结果；若失败，保留失败截图及当次应用日志。
