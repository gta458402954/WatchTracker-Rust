## 1. 目标与范围

当前顶部同时暴露搜索、保存视图、高级筛选、排序、显示模式、看板、添加、锁定和多个同步入口，主操作层级过密，部分功能重复。此次改造沿用用户已确认的效果方案，减少第一行按钮数量，同时保留所有现有能力。

效果方案只约束顶部工具栏、快捷筛选和弹出菜单。卡片样式、海报布局、平台标签、演员导演等内容展示不在本任务范围内。

## 2. 最终信息架构

### 2.1 第一行：主工具栏

从左到右固定为：

1. 品牌区：场记板、Git 短码、影视追踪；整体不换行、不压缩。
2. 保存视图：独立下拉入口，不与高级筛选合并。
3. 搜索：占用剩余空间，并保持可用的最小宽度。
4. 高级筛选：独立入口并显示高级条件数量。
5. 排序：保留现有语义。
6. 同步：一个状态化入口，取代重复的手动同步和自动同步按钮。
7. 设置：齿轮保持一级可达。
8. 更多：承载低频操作。

“更多”菜单第一版顺序：

1. 添加记录（可补充 `Ctrl+N` 快捷键）。
2. 列表 / 海报显示模式。
3. 数据看板。
4. 分隔线。
5. 后续新增的低频操作。

不新增尚无对应功能的帮助按钮。

### 2.2 第二行：快捷筛选

继续展示媒体类型、观看状态和地区。锁定筛选从第一行移至第二行末尾，成为唯一锁定入口。高级筛选摘要只在确实存在高级条件时显示在后续行，不占用常驻空间。

### 2.3 同步状态菜单

同步入口只整合展示和操作入口，不改写现有同步状态机：

| 状态 | 展示建议 |
| --- | --- |
| 正常 / 最近成功 | 绿色 |
| 暂停、待处理、等待重试 | 黄色 |
| 失败或存在冲突 | 红色 |
| 正在同步 | 蓝色并显示进行中反馈 |

点击仅打开状态面板，不得自动发起同步。面板提供：立即同步、暂停/恢复、待处理数量、冲突数量、最近成功时间和打开同步设置。每项业务操作继续调用现有目的限定入口。

### 2.4 地区收敛

- 桌面默认直接显示前 7 个地区。
- 当前活动地区必须提升到直接可见区域，包括由保存视图恢复但当前零匹配的条件。
- 其余地区进入“更多地区”；“未知地区”始终可以访问。
- 窄屏根据可用宽度减少直接展示数量，不通过压扁文字解决空间问题。
- 不改变“只按条目第一个国家筛选”的现有业务语义。

## 3. 响应式与可访问性

- 1200 px 常规桌面宽度下，第一行不出现竖排文字或意外折行。
- 品牌与图标按钮使用不可收缩、不可换行约束；搜索框使用弹性宽度和明确最小宽度。
- 760 px 以下允许工具栏容器内部横向滚动，但文档页面本身不得出现横向溢出。
- 360 px 下仍能访问全部操作和筛选。
- 菜单与弹出层使用 Portal，避免被滚动容器裁切。
- 触发器提供可访问名称、`aria-expanded` 和菜单关联；支持 Escape、外部点击关闭、键盘导航及关闭后焦点返回。
- `Ctrl+N` 若实施，只能在非输入态触发，不得干扰搜索框或表单输入。

## 4. 数据与安全边界

本任务为纯界面和派生状态改造：

- 数据库继续使用 V18。
- 不修改 records 或 settings schema。
- 不修改 `WatchlistQueryV1`、保存视图持久化格式和启动视图语义。
- 不修改 WebDAV、暂存库、发布意图、outbox 或冲突状态机。
- 仅打开同步菜单、更多菜单或地区菜单时，不得产生 IPC 写入或网络请求。
- 移动入口不得改变添加、显示模式、看板、锁定、排序或同步原有业务效果。
