# TASK-D-UX-001-R1：高级筛选界面去重修订计划

> 状态：IMPLEMENTED
> 日期：2026-08-09
> 前置任务：`TASK-D-UX-001`（已实现）
> 数据边界：只调整界面与派生状态；不修改 `WatchlistQueryV1`、V18、records、settings schema 或 WebDAV

## 1. 修订目标

保留 `TASK-D-UX-001` 已完成的统一查询与保存视图能力，解决同一筛选条件同时出现在顶部快捷栏、高级面板、条件摘要和保存视图栏中的视觉重复。

完成后界面分工固定为：

- 顶部快捷栏：媒体类型、观看状态、地区、锁定状态。
- 搜索框：仅负责文字搜索。
- 高级筛选：平台、题材、内容标签、上映年份、个人评分、IMDb 评分。
- 视图下拉框：选择、保存、更新、设为启动和删除视图。
- 条件摘要：只显示高级筛选条件，不重复顶部已可见的选择。

## 2. 顶部布局

桌面端从左到右调整为：

1. 图标、Git 短码和“影视追踪”。
2. `视图：全部记录` 下拉入口。
3. 搜索框。
4. `高级筛选 N`。
5. 排序。
6. 锁定三态按钮。
7. 同步、显示模式、看板、设置和添加等既有操作。

要求：

- `N` 只统计六类高级条件，不统计搜索、媒体类型、状态、地区或锁定状态。
- 没有高级条件时显示“高级筛选”，不显示 0。
- 保留当前顶部横向安全滚动，页面本身在 360 px 不出现横向溢出。

## 3. 保存视图下拉框

删除永久占据整行的 `SavedViewBar`，新增紧凑 `SavedViewMenu`：

- 关闭状态显示：`视图：全部记录`、当前视图名，或`临时筛选`。
- 展开后显示内置“全部记录”和最多 20 个用户视图。
- 启动视图使用星标，当前视图使用选中态，已临时修改显示“已修改”。
- 保留现有“另存为、更新、设为/取消启动、删除”能力，不增加新的数据字段。
- 删除当前视图后仍保留当前条件并显示“临时筛选”。
- 保存失败时下拉面板保持打开，继续使用固定安全错误文案。

交互语义使用带名称的弹出面板，不强行套用不合适的 ARIA `menu` 键盘模型；入口设置 `aria-expanded` 和 `aria-controls`，面板内继续使用标准按钮与表单控件。

## 4. 高级筛选面板

从 `AdvancedFilterPanel` 删除以下可编辑控件：

- 媒体类型。
- 观看状态。
- 地区。
- 锁定状态。

面板只保留：

- 平台。
- 题材。
- 内容标签。
- 上映年份范围。
- 个人评分范围。
- IMDb 评分范围。

面板顶部增加只读说明：“媒体类型、状态、地区和锁定条件请使用顶部快捷筛选”。若这些基础条件已启用，可显示一行简短只读摘要，但不提供第二套按钮。

面板底部的“清除筛选”改为“清除高级条件”，只清空上述六类高级条件，不影响顶部快捷条件、搜索、排序或显示模式。

## 5. 条件摘要

`ActiveFilterSummary` 只渲染：

- 平台。
- 题材。
- 内容标签。
- 上映年份。
- 个人评分。
- IMDb 评分。

媒体类型、状态、地区、锁定和搜索不在摘要中重复出现。摘要为空时整行不渲染；右侧按钮改为“清除高级条件”。

主列表无结果时仍提供两个入口：

- “修改高级筛选”。
- “重置全部条件”：清除统一查询，但保留现有排序与显示模式，避免把筛选重置与界面偏好混为一谈。

## 6. 保持不变的业务规则

- `WatchlistQueryV1` 和同字段 OR、跨字段 AND 语义不变。
- 顶部快捷按钮仍写入统一查询，不创建第二套状态。
- 地区仍只使用条目的第一个国家。
- 保存视图仍包含搜索、全部查询条件、排序与显示模式。
- 保存视图仍只写现有本机 settings，不进入 WebDAV/outbox。
- 消失或未来条件仍保持不匹配，不静默放宽结果。
- 默认启动“全部记录”，只有明确指定的启动视图才自动应用。

6. 执行完整前端、Playwright 与 Rust 回归，更新路线图。
