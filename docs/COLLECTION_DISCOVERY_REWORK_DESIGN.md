# TASK-D-UX-003-R2：收藏集发现、缺失条目与元数据补充重构

> 状态：IMPLEMENTATION（2026-08-10）  
> 数据库主版本：继续使用 V18  
> 前置：`TASK-D-UX-003-R1`

## 目标

修正具体收藏集误触发全片库 IMDb 扫描、完整已有系列仍被推荐、中文季数拆组、手工系列不能绑定 TMDB、影视宇宙不能检查成员剧集缺失季、记录编辑页不能创建收藏集，以及缺失季自动创建未继承国家/题材/平台/时长的问题。

## 产品边界

- “扫描片库归组建议”是唯一全局扫描入口；具体收藏集只按稳定 TMDB 身份定向检查。
- 电视剧系列检查缺失季，电影系列检查缺失电影，影视宇宙同时提供检查缺失条目与关联相关作品。
- TMDB 不提供通用影视宇宙完整关系图；衍生作品保持搜索、预览、用户确认。
- 扫描和预览零业务写入；多个匹配必须选择；旧数据不在启动时自动整理。

## 识别与差异

- 季数支持阿拉伯数字、中文数字、`Season N`、`Sxx` 和 `SxxExx`；中文名和原文名联合确定基础标题与季数，冲突时不得自动写入。
- 优先按 `tmdbParentId`、`tmdbId`、季编号和 `sourceKey` 归组；IMDb 与标题仅作后备。
- 完整已有集合隐藏；部分已有只展示缺少记录；应用成功后立即移除或更新建议。
- 本地已有季与 TMDB 总季数分别展示；特别篇和未播出季默认不选。

## 收藏集类型与来源

创建入口提供普通、电视剧系列、电影系列和影视宇宙。手工电视剧/电影系列可以先以 `sourceKind=manual` 创建；成员具有唯一父剧身份时，用户确认后绑定稳定 `sourceKey`。成员指向多个父剧时必须修正成员或转为影视宇宙。

影视宇宙从成员提取不同父剧；单一父剧直接检查，多父剧先选择。新增季可同时属于当前宇宙和既有电视剧系列，不静默创建额外系列。

## TMDB 元数据映射

所有季创建/填充入口复用同一映射器。季级字段取季名称、编号、播出年份、海报、总集数与季 ID；父剧级字段继承 IMDb、题材、ISO 国家、地区标签、网络/平台、状态、评分、单集时长和父剧 ID。已有记录只填缺失字段，不覆盖人工维护值；TMDB 空值不得清空本地字段。

## 记录内创建收藏集

“整理与归组”在零收藏集时仍显示。管理器可创建四种收藏集草稿；草稿仅随记录表单存在，取消记录编辑即丢弃。保存时 Rust `create_collection_for_record` 在一个事务内创建收藏集和当前成员关系，避免空集合。完整的记录与既有成员差异仍沿用现有保存语义，后续若扩大为跨实体单命令必须保持 revision、generation、staging 和 outbox 同事务。

## 性能与缓存

当前集合按父剧/电影合集去重请求；全局扫描依次使用现有 TMDB 身份、IMDb 后备和本地标题候选。成功身份缓存 30 天、无结果 7 天、全部季 7 天；手动重新检查可绕过。最多四路并发，可停止且不把取消显示为失败。

## 验收重点

- 小谢尔顿第 1、5 季归为一个本地系列。
- 完整的实习医生格蕾不再推荐，部分存在只显示差异。
- 芝加哥烈焰检查只读取其父剧；影视宇宙可以选择多个父剧。
- 黑镜自动创建季继承 `GB`、题材、地区标签、平台和单集时长。
- 手工电视剧系列可确认 TMDB 后检查缺失季。
- 记录编辑页可暂存新集合，取消零写入，保存后集合与当前成员同时存在。
- 保持 V18，旧记录和未归类数据不被启动流程修改。

## 2026-08-10 实施补充

- 本地父剧身份与正式收藏集统一使用 `tmdb:tv-show:<id>`，本地/TMDB 重复候选合并；匹配已有收藏集后只保留真实缺少成员，完整集合不再建议。
- 普通手工收藏集若成员只有一个稳定父剧，可在用户确认后按需升级为电视剧系列并检查缺失季；不做启动时批量迁移。
- 中文名、原文名或进度中的季编号互相冲突时停止自动归组；TMDB 返回多个候选时进入用户选择，不再采用第一项。
- 全部季与电影合集结果缓存 7 天，并提供显式“刷新 TMDB”；已有父剧身份的记录不再重复执行 IMDb 搜索。
- 电影系列支持读取 TMDB 合集、排除已有/未上映电影并选择性补充；Rust 在提交时按 TMDB movie ID 二次阻止重复。
- 影视宇宙补充新季时，如果已经存在绑定同一父剧的电视剧系列，会在同一事务中把新记录加入两者。
- TMDB 建议的来源绑定与成员添加改为一个 Rust 目的限定命令，revision、generation、staging 和 outbox 保持同事务；失败时全部回滚。
